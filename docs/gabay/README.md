# Mga Gabay ng LNDH

Talaan ng maiikling gabay para sa pang-araw-araw na pagpapaunlad ng LNDH v2.
Layunin nitong magsilbing mabilis na sanggunian sa terminal, PlatformIO, at Git.

## Nilalaman

| Gabay | Gamit |
| --- | --- |
| [Daloy sa Terminal](workflow-terminal.md) | Pangkalahatang daloy mula simula ng trabaho hanggang commit. |
| [PlatformIO](commands-pio.md) | Build, upload, serial monitor, device list, at clean commands. |
| [Git](commands-git.md) | Status, diff, add, commit, branch, push, revert, reset, at stash. |
| [Daloy sa Git](workflow-git.md) | Inirerekomendang hakbang bago mag-commit at mag-push. |

## Mabilis na Simula

Kung hindi sigurado kung saan magsisimula, basahin muna ang
[Daloy sa Terminal](terminal.md). Gamitin ang [PlatformIO](pio.md) kapag firmware
ang sinusuri, at [Daloy sa Git](workflow-git.md) kapag handa nang mag-commit.

# Talasalitaan ng mga Teknikal na Terminolohiya

Upang magkaroon ng konsistensi sa dokumentasyon, narito ang mga itinakdang kahulugan:

| Terminolohiya | *Terminology* | Depinisyon |
| --- | --- | --- |
| Ekosistema | Ecosystem | Ang kabuoang ugnayan ng lahat ng proyekto sa ilalim ng LNDH (SLH, YMK, YTD, at HKL). |
| Hugpong | Node | Isang indibidwal at nagsasariling yunit sa loob ng ekosistema. Ang YMK ay isang hugpong. |
| Sistema | System | Ang kabuoan ng mga mekanismo sa loob ng isang hugpong upang gumanap sa itinakdang tungkulin nito. |
| Subsistema | Subsystem | Malalaking dibisyon ng mga gawain sa loob ng isang sistema (hal. Subsistema ng Input, Subsistema ng Komunikasyon). |
| Modyul | Module | Ang pinakamaliit na yunit ng pag-andar (functional unit) na maaaring ihiwalay, palitan, o i-scale. Maaaring ito ay pisikal (hardware) o lohikal (software) |
| Materyal | Hardware | Ang mga pisikal na sangkap, kagamitan, at elektronikong bahagi ng hugpong. | 
| Tatagsil | Firmware | Ang mga instruksiyong nakaukit sa mikorkontroler na nagsisilbing tulay ng lohika at materyal. (Mula sa "Tatag" + "Silid"). |
| Lohika | Logic | Ang daloy ng pagpapasya, algoritmo, at matematikong proseso na nagpapatakbo sa programa. | 
| Programa | Program | Ang koleksiyon ng mga kodigo at instruksiyon na nagpapatakbo sa kabuoan ng hugpong. |
| Telemetriya | Telemetry | Ang datos na ipinapadala mula sa SLH patungo sa YMK o HKL para sa pagsubaybay. | 
| Atas | Command | Ang instruksiyong nanggagaling sa opereytor mula sa YMK o HKL patungo sa SLH. |
